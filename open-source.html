Open-source components

The processing libraries retain their own authors and licenses.

Last updated: September 24, 2026

What this page covers

This is a readable summary of major components used in the current Android build, not a replacement for the exact license notices accompanying a release. The app's Settings → About → Open-source licenses shows a component inventory. A public release must include all required notices and satisfy source/relinking obligations for the precise packaged binaries.

Major components

  • AndroidX Compose, Lifecycle, WorkManager, DocumentFile and ExifInterface — primarily Apache License 2.0.
  • PDFBox Android, Apache Commons Compress, Commons CSV and Commons IO — Apache License 2.0.
  • FFmpegKit maintained (non-GPL full variant) — LGPL 3.0 obligations require distribution review; components and native configurations must be checked before release.
  • junrar — UnRAR License, used for RAR reading/extraction, not RAR creation.
  • XZ for Java — 0BSD; Smart Exception — BSD 3-Clause.
  • SnakeYAML — Apache License 2.0; Google Play In-App Update — Google's applicable terms rather than an open-source license.

Açık kaynak bileşenler

İşleme kütüphanelerinin hakları ve lisansları kendi sahiplerinde kalır.

Son güncelleme: 24 Eylül 2026

Bu sayfanın kapsamı

Bu, mevcut Android sürümündeki başlıca bileşenlerin anlaşılır bir özetidir; yayımlanan sürümle sunulması gereken tam lisans bildirimlerinin yerine geçmez. Uygulamanın Ayarlar → Hakkında → Açık kaynak lisansları bölümünde bileşen envanteri vardır. Genel yayında tam paketlenen ikili dosyalara ilişkin bildirim ve kaynak/yeniden bağlama yükümlülükleri yerine getirilmelidir.

Başlıca bileşenler

  • AndroidX Compose, Lifecycle, WorkManager, DocumentFile ve ExifInterface — ağırlıkla Apache Lisansı 2.0.
  • PDFBox Android, Apache Commons Compress, Commons CSV ve Commons IO — Apache Lisansı 2.0.
  • FFmpegKit maintained (GPL olmayan full çeşidi) — LGPL 3.0 yükümlülükleri dağıtım incelemesi gerektirir; paketlenen bileşen ve yerel yapılandırmalar yayımdan önce kontrol edilmelidir.
  • junrar — UnRAR Lisansı; RAR oluşturmak için değil, okumak/çıkarmak için kullanılır.
  • XZ for Java — 0BSD; Smart Exception — BSD 3-Clause.
  • SnakeYAML — Apache Lisansı 2.0; Google Play uygulama içi güncelleme — açık kaynak lisansı yerine geçerli Google koşullarına tabidir.
